# Assets

Folder asset production bersama.

## Struktur yang digunakan

- `clients/` — logo client.
- `detail.css` — stylesheet halaman selain homepage.
- `detail.js` — interaksi shared halaman selain homepage.

## Struktur untuk asset baru

Gunakan:

```
assets/projects/{project-slug}/
assets/journal/{article-slug}/
assets/brand/
```

Gunakan **lowercase kebab-case** tanpa spasi untuk semua file baru. Prioritaskan WebP/AVIF untuk foto web dan SVG/PNG transparan untuk logo bila diperlukan.
